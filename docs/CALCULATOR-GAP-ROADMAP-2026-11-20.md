# מפת פיתוח — פערי מחשבונים מול מתחרים (20.11.2026)

מקור הפערים: השוואה לתפריט האתרים calculatzia.com ו-delekulator.co.il. אין להעתיק קוד או נתונים מהם: כל מספר מגיע ממקור רשמי ומתועד.

## כללי עבודה
- שכבות: `lib/constants` או `lib/data` (נתונים עם מקור ותאריך אימות) → `lib/calculators` (מנוע טהור + בדיקות ב-`tests/unit`) → `components/calculators` (ווידג'ט) → `app/<קטגוריה>/<slug>/page.tsx` (עם `CalculatorLayout`, FAQ, canonical משלו).
- אחרי כל מחשבון: רישום ב-`lib/config/all-calculators.ts`, `lib/config/related-calculators.ts`, `app/sitemap.ts`, `public/llms.txt`, ודף הקטגוריה.
- שער: `npx tsc --noEmit && npm test && npm run build`.
- ממשקי API חיים: אין צורך בחדשים. שער דולר כבר מבנק ישראל עם גיבוי `open.er-api.com` ב-`components/layout/Ticker.tsx`.
